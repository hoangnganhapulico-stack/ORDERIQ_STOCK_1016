🏢 Danh sách NCC (Mã + Tên)
Để cột Tên NCC luôn đủ. Nạp file bất kỳ có 2 cột Mã NCC và Tên NCC (vd danh sách NCC từ hệ thống). Mã còn thiếu tên có thể nhập tay ở mục Tham số.
🔧 Kiểm tra cột
Tool tự nhận cột theo tên chuẩn của file xuất từ hệ thống. Chỉ khi thiếu cột bắt buộc hoặc không nhận ra tháng, tool mới hỏi lại.
• Tồn kho - bắt buộc: Barcode, Product Name, Sales Qty, Close Qty. Nên có: Open/Income/Close Cst, Sales Amt, G.P.Amt(COGS), G.P.%(COGS), Supplier Code, Layer1, Order Group Name, M.A.C. Tháng lấy từ tên file (InventoryPLU_..._20260829084353) hoặc cột Target Month. Nạp 3-6 tháng trở lên để có lịch sử; 12-13 tháng để so cùng kỳ.
• Giao dịch - bắt buộc: Barcode, QTY. Cột Layer1 Code + Layer1 giúp tool tự đặt tên cho CAT.
• PO Detail - dùng đúng file xuất PODetail (có dòng tiêu đề phụ ở trên cũng được). Tên NCC trong file PO được dùng cho toàn bộ tool.
